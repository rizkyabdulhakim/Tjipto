# Sitasi Hukum Indonesia Tjipto

Sitasi publik dibentuk hanya dari `CitationUnit` terverifikasi. Urutan bentuk lengkap:

```text
jenis + nomor + tahun, judul resmi, ketentuan, identitas pengundangan, halaman
```

Penyebutan berikutnya memakai jenis, nomor, tahun, dan ketentuan. Nomor catatan kaki
ditetapkan dari urutan kemunculan pertama dan dideduplikasi dengan `evidence_key`;
teks bebas tidak dapat mengganti identitas resmi, sumber, halaman, kewenangan,
finalitas, atau nomor catatan kaki.

Fakta dari halaman katalog resmi dapat disitasi dengan URL katalog, tetapi tidak
mendapat selector PDF atau highlight kecuali nilai yang sama diverifikasi secara
terpisah dari PDF resmi.
